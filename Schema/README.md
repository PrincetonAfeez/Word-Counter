# Word Counter Schema

This folder contains simple JSON Schema files for the Word Counter project.

The schemas describe common request and response objects for a streaming-first word-counting CLI/API, including input sources, analysis options, text statistics, word-frequency rows, readability scores, command requests, diff results, multi-source results, and history records.

These schemas are intentionally lightweight starter contracts. They can be used for validation, API planning, CLI JSON output documentation, or future test data.
